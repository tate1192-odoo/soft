# soft

Softteknik Bilişim'in Odoo 19 eklentileri (soft modülleri).

## Dal düzeni

- `19.0` — Odoo 19 serisi (aktif geliştirme)
- `main` — varsayılan dal; `19.0` ile senkron tutulur

## Notlar

- Modüller bu deponun kökünde tek klasör olarak durur (`activities_pano/`, `master_sale/`, ...).
- Odoo `addons_path` bu deponun kökünü gösterecek şekilde ayarlanır.
- Lisans: LGPL-3 (modül manifestolarındaki `license` alanı geçerlidir).
